DX Monitor

Same live decode feed as Live Monitor, grouped by DXCC entity instead of shown as a flat log -- most recently-heard entity on top, with up to 3 of its most recently-heard distinct callsigns underneath. Colors match Live Monitor's worked/confirmed/none scheme, scoped to band. Each station's own band and radio frequency (at the time it was heard) is shown next to it. The six boxes after each callsign show how often it's been decoded in six consecutive 15-minute windows covering the last 90 minutes -- hover a box for the exact count. Entities disappear after 3 hours with no activity. Filter to Everything / Current band / Current band + frequency; Clear removes only what the current filter shows -- WSJT-X's own Erase doesn't touch this screen, since this is meant to keep a longer history than the live decode window does. Double-click a callsign to call it -- retunes the radio to the frequency it was last heard on first, if the radio isn't already there, then replies exactly as double-clicking that decode in WSJT-X itself would.
