DX Monitor

Same live decode feed as Live Monitor, grouped by DXCC entity instead of shown as a flat log -- most recently-heard entity on top, with up to 3 of its most recently-heard distinct callsigns underneath. Colors match Live Monitor's worked/confirmed/none scheme, scoped to band. Each station's own band and radio frequency (at the time it was heard) is shown next to it. The six boxes after each callsign show how often it's been decoded in <15m / 15-30m / 30-60m / 1-2h / 2-3h / 3-6h windows, normalized to a common per-15-minute rate so the boxes are directly comparable despite their different widths -- hover a box for the exact count. Filter to Everything / Current band / Current band + frequency; Clear removes only what the current filter shows -- WSJT-X's own Erase doesn't touch this screen, since this is meant to keep a longer history than the live decode window does.
