WSJT-X Remote

Remote control surface for WSJT-X. Most controls go over its UDP API; a few (Stop, Monitor, Decode, Enable Tx, Tune, and the mode buttons) have no UDP equivalent at all and instead drive WSJT-X's own window directly -- see the hint text below the button row if that stops working (it needs WSJT-X running, Accessibility permission, and pyobjc-framework-Quartz installed). Enable Tx and Tune genuinely arm/key the transmitter when checked -- turning either off goes through the ordinary Halt Tx UDP command, not another GUI click. The band-select buttons below tune the rig directly via rigctld (same connection as the Radio tab) instead of clicking WSJT-X's own band button -- edit which presets show there on the Frequencies tab.
