RigDial

Hardware remote control via a Contour ShuttleXpress (5 buttons + jog wheel + shuttle ring), driving the same rigctld connection as the Radio tab -- no Flrig involved. Frequency presets now live on their own Frequencies tab -- check a preset's "RigDial" box there to include it in band_up/band_down/ cycle_presets below. Needs the hid Python package plus a native hidapi library installed (e.g. port install hidapi or brew install hidapi) -- see the connection status below if the dial isn't showing up.
